# Geometrical Calculator

**Version:** V1.2

## About
Geometrical Calculator is a Python project that calculates geometric measurements using separate modules for different mathematical operations.

## Features
- **Perimeter:** Perimeter calculations for supported shapes.
- **Area:** Area calculations for supported 2D shapes.
- **TSA & CSA:** Total and curved surface area calculations for supported 3D shapes.
- **Volume:** Volume calculations for supported 3D shapes.
- **Input validation:** Checks user input to help prevent invalid entries.
- **Return-to-menu system:** Allows users to continue calculating without restarting the program.

## Project Structure
- `main.py` — Main menu and program flow.
- `constants.py` — Mathematical constants and helper functions.
- `perimeter.py` — Perimeter calculations.
- `area.py` — Area calculations.
- `tsa.py` — Surface area calculations.
- `volume.py` — Volume calculations.

## Requirements
- Python 3

## How to Run
1. Clone or download this repository.
2. Open the project in a Python IDE, such as PyCharm.
3. Run `main.py`.

## Development
The project is developed incrementally, with features, improvements, and bug fixes introduced across versions.
